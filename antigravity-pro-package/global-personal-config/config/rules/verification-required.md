# قاعدة التحقق الإلزامي (دائمة التفعيل)

- لا تدّعِ "تم بنجاح" أو "المهمة مكتملة" دون دليل ملموس: نتيجة تشغيل
  فعلية، رقم، سجل (log)، أو اختبار ناجح تُظهره لي.
- عند إنهاء أي مهمة تبرمج أو تحليل بيانات، اذكر طريقة التحقق التي
  استخدمتها (مثال: "شغّلت الاختبار X وأعطى Y").
- إن تعذّر عليك التحقق فعليًا (مثل مهمة تتطلب جهازي أنا)، صرّح بذلك
  بوضوح بدل الإيحاء بأن التنفيذ تم.
