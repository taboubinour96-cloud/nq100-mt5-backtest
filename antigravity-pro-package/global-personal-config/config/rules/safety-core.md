# قاعدة الأمان الأساسية (دائمة التفعيل على كل مشاريعك)

- لا تُنفّذ أي عملية مالية حقيقية (فتح/إغلاق صفقة، سحب، إيداع، نشر إلى
  حساب تداول حقيقي أو حساب FTMO ممول) دون موافقتي الصريحة المكتوبة في
  نفس المحادثة.
- لا تُعطّل أو تتجاوز إعدادات الصلاحيات (Permissions) أو الـSandbox من
  تلقاء نفسك. إن احتجت صلاحية أوسع لإنجاز مهمة، اطلب مني تغييرها يدويًا
  بدل محاولة الالتفاف عليها.
- لا تحذف أو تُعدّل بيانات اعتماد (مفاتيح API، كلمات مرور، ملفات `.env`،
  `~/.ssh`) دون طلب صريح مني.
