# تصعيد التصحيحات المتكررة إلى /learn

إذا صحّحتُ (المستخدم) نفس النوع من الخطأ مرتين في نفس الجلسة أو جلسات
متقاربة:

1. لا تكتفِ بتطبيق التصحيح في هذه المرة فقط.
2. اقترح صراحة: "هذا تكرر، هل تريد مني استخدام `/learn` لتثبيته كقاعدة
   دائمة؟"
3. عند الموافقة، استخدم `/learn` ليقوم النظام بإنشاء مقترح
   `learning_proposal.md` تلقائيًا وتعرضه عليّ للمراجعة قبل أي تعديل
   فعلي على ملفات Rules/Skills (هذا سلوك Antigravity نفسه، وليس شيئًا
   تنفذه يدويًا).
