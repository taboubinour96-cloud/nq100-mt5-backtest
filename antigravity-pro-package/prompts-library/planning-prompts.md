# قوالب برومبت للتخطيط والتحقق (مبنية على أوامر رسمية مؤكدة)

## 1. قبل أي مهمة متعددة الملفات
```
/plan /grill-me
المطلوب: <اكتب الهدف بالضبط>
السياق والمدخلات: <اذكر الملفات/الوحدات ذات الصلة>
القيود: <ممنوعات صريحة>
التحقق: <كيف سأعرف أن المهمة تمت بنجاح>
```
`/grill-me` يجعل الوكيل يطرح عليك أسئلة توضيحية قبل أي تعديل فعلي —
موثّق في `/docs/slash-commands`.

## 2. لمهمة تحتاج استقلالية كاملة حتى الإنجاز
```
/goal
<اكتب الهدف النهائي بدقة + معايير النجاح>
```
يعمل على كل الخطط (ليس حصرًا على المدفوعة) — الوكيل يكمل المهمة بدون
توقف للمراجعات المتكررة.

## 3. لسؤال جانبي لا تريد أن يُفسد سياق المحادثة الرئيسية
```
/btw <سؤالك هنا>
```
يُنفَّذ في فرع قراءة فقط منفصل عن المحادثة الأساسية.

## 4. لتثبيت درس بعد تصحيح متكرر
```
/learn
```
أو مباشرة:
```
/learn <صف الدرس بدقة: ماذا حدث خطأ، وماذا يجب أن يحدث بدلاً منه>
```
تذكّر: Antigravity سيعرض عليك `learning_proposal.md` للموافقة قبل أي
تعديل فعلي على ملفات Rules/Skills — لن يُفاجئك بتغيير صامت.

## 5. لتحرير سياق ممتلئ دون فقدان الزبدة
```
/compact
```
