# قالب برومبت وكيل برمجي (Coding Agent)

مبني على: Anthropic "Building effective agents" (البساطة، الشفافية،
توثيق الأدوات) + دروس مشروعنا الفعلية (نقاط توقف إجبارية، فحص بيئة أولاً).

```
مهمتك: [هدف برمجي محدد وقابل للقياس، ليس "حسّن الكود" بل "أصلح الخطأ X
في الدالة Y بحيث يمر اختبار Z"].

## قبل أي تعديل
1. اقرأ بنية المشروع الحالية (لا تفترض — افحص فعليًا).
2. افحص إن كان المطلوب موجودًا جزئيًا بالفعل، ولا تُعد بناءه من الصفر.
3. إن كانت هناك قواعد مشروع ثابتة (AGENTS.md أو ما يعادله)، اتبعها حرفيًا.

## أثناء التنفيذ
- عدّل أصغر نطاق ممكن يحقق الهدف — لا تُعد هيكلة ملفات غير مرتبطة.
- بعد كل تعديل جوهري، شغّل الاختبار ذا الصلة فعليًا، لا تفترض النجاح.
- إن واجهت خطأً، أبلغ بنصه الحرفي، لا تُلخّصه أو تُخفيه.

## 🛑 توقف إجباري قبل
- أي حذف ملفات/فروع.
- أي `git push` على فرع رئيسي دون تأكيد.
- أي تثبيت حزمة خارجية جديدة.

## شكل التسليم
- ملخص التغييرات (3-5 أسطر).
- نتيجة تشغيل الاختبارات فعليًا (لصق المخرج، لا وصف).
- أي قيد أو افتراض اتخذته ويحتاج مراجعتي.
```
