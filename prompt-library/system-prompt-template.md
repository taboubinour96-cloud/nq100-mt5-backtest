developer/system > user > مخرجات الأدوات) + Google Gemini 3 (ضع القيود
الحرجة في البداية، مباشر ومقتضب لا مطوَّل).

## ملاحظة خاصة بكل نموذج
- **Gemini 3.x**: ضع القيود الحرجة والـpersona في البداية، استخدم وسوم
  XML أو Markdown متسقة لفصل الأقسام، لا تُسهب — النموذج يُفرط التحليل
  في التعليمات المطوَّلة المصمَّمة للنماذج الأقدم.
- **Claude**: استخدم وسوم XML (`<role>`, `<constraints>`, `<output_format>`)
  — موثّق أنها تقلل الغموض فعليًا.
- **GPT (عبر Responses/Chat API)**: رسالة `developer` لها أعلى سلطة —
  ضع فيها القواعد الثابتة فقط، لا محتوى ديناميكي/مستخدم.
