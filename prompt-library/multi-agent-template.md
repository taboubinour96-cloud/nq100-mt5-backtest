# قالب تنسيق متعدد الوكلاء (Multi-Agent / Agent Manager)

مبني على: Anthropic "Building effective agents" (Orchestrator-Workers،
Evaluator-Optimizer) + Antigravity Agent Manager الموثَّق فعليًا في هذا
المشروع.

## نمط Orchestrator-Workers (مهام متوازية مستقلة)
```
وزّع هذه المهمة على عدة وكلاء، كل واحد بنطاق ملفات غير متداخل تمامًا مع
الآخرين (مثال: وكيل1 → ea/، وكيل2 → ict_engine/، وكيل3 → results/).
لا تسمح لوكيلين بالكتابة في نفس الملف في نفس الجلسة — آخر كتابة تفوز
بصمت بدون دمج (مشكلة حقيقية موثّقة، لا نظرية).
كل وكيل يُنتج Artifact (ملخص ما فعل) مستقل تُراجعه أنت قبل الدمج.
```

## نمط Evaluator-Optimizer (حلقة تحسين تكرارية)
```
وكيل أ (المنفِّذ): ينفّذ [المهمة] وينتج نتيجة ملموسة (بيانات/كود/تقرير).
وكيل ب (المقيِّم): يراجع نتيجة (أ) مقابل [معيار نجاح رقمي محدد مسبقًا]،
ولا يصدر رأيًا نوعيًا غامضًا بل درجة/رقم قابل للمقارنة بين الجولات.
كرّر حتى [شرط توقف رقمي محدد]، لا "حتى يصبح جيدًا" غامضة.
```
